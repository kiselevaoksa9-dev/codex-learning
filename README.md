# Панель проектов

Простое веб-приложение на русском языке: четыре проекта, статусы, ближайшие задачи, ответственные и сроки. Есть поиск по названию и адаптивный интерфейс для телефона.

## Запуск

Из каталога репозитория выполните:

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

Откройте порт 8000 в браузере. Зависимости устанавливать не нужно.

Демонстрационные данные находятся в `app.js`; они не сохраняются на сервере. Стили — в `styles.css`, разметка — в `index.html`.
